# Granular Ball Computing (GBC) — Experimental Repository

An experimental repository dedicated to exploring, implementing, and evaluating **Granular Ball Computing (GBC)** and its potential applications in machine learning.

This repository serves as a research and testing ground for developing GBC-based algorithms, experimenting with granular ball generation and splitting strategies, investigating classification and regression techniques, and exploring hybrid architectures that combine GBC with conventional neural networks and other learning methods.

The primary objective is to understand the computational advantages, limitations, and potential of granular representations as an alternative or complement to traditional machine learning approaches.

**Areas of exploration:**
- Granular ball generation, splitting, and optimization.
- Classification and regression using granular representations.
- GBC-based feature extraction and dimensionality reduction.
- Hybrid GBC–neural network architectures.
- Backpropagation and adaptive granular ball optimization.
- Kernel-based learning and decision boundaries.
- Benchmarking against conventional machine learning algorithms.

Different areas of application would be present in different branches.
